Welcome!




This is a SpringBoot PostgreSQL example using JPA, Thymeleaf, REST.

The Model layer loads any database thru properties alone.
  • Objects are dynamically populated without added DAO, Service, & Repository coding.
  • Full CRUD operations are already possible!
  • The View layer uses Thymeleaf templates and is easily programmable.
  • It defaults to HTML, which makes it easy for anyone to alter or add CSS/JS/Bootstrap...
  • The Controller is minimal and REST based.
  • It can easily be configured for app to app activity.
